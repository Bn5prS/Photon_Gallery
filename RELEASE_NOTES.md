# Release Notes — v4.2.1

### New Features & Improvements
* **Video Controls Quick Sheet**: Adjust playback speed (0.25×–2.0×), rotate 90°, toggle loop playback, and switch between Fit / Fill aspect modes directly from the video player bottom sheet.
* **Adaptive 1:1 Square Mosaic Grid**: Dynamic editorial hero variations (Left, Center, Right, and Twin Heroes) with strict row-by-row reading order and 100% 1:1 square tiles.

---

### Bug Fixes
* Fixed external image launch where photos failed to remain open or crashed when opened from third-party apps (#49).
* Fixed video player rotation and Fit / Fill aspect mode scaling using hardware-accelerated TextureView.
* Fixed navigation swipe order across date groups in mosaic layout to match visual row-by-row sequence.
