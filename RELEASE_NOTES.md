# Release Notes — v4.2.0

### New Features
* **Redesigned Photo Map** with a draggable bottom sheet, circular photo pins, place chips, search bar, preview card, and map style switcher.
* Added **AI Indexing Folder Controls** in Settings to include or exclude folders per feature (Smart Search, OCR, and People) (#46).
* Added **Settings Backup & Restore** (JSON export/import).
* Added a **Default Startup Tab** option in Settings.

---

### Improvements
* Upgraded the **Stories Carousel** to a taller portrait layout with progress pills (#47).
* Upgraded **Editorial Mosaic** to a clean square hero grid layout.
* Improved **Smart Search** relevance and reduced unrelated results.
* Improved **Face Recognition & Clustering** accuracy.
* Cleaned up **Places** and **People** screens by removing duplicate icons and filter pills.

---

### Bug Fixes
* Fixed a crash when opening **Photo Map** on devices using hardware bitmaps (#48).
* Fixed photo count text wrapping onto two lines on People cards.
* Fixed duplicate flashback entries in Memories reels.

---

### Downloads & Assets
* **PhotonGallery-arm64-v8a.apk** — Recommended for 64-bit ARM devices (Android 12+)
* **PhotonGallery-universal.apk** — Compatible across all supported architectures
