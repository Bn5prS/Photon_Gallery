### ⚡ Building from Source

#### Prerequisites
- **Android Studio** (Meerkat / Ladybug or newer)
- **JDK 17** or **JDK 21**
- **Android SDK** with platform `API 37` installed

#### Clone & Build

```bash
# 1. Clone the repository
git clone https://github.com/Bn5prS/Photon_Gallery.git
cd Photon_Gallery

# 2. Check compilation
./gradlew compileDebugKotlin

# 3. Assemble release APK
./gradlew assembleRelease

# 4. Install onto your connected Android device
adb install -r app/build/outputs/apk/release/PhotonGallery-arm64-v8a.apk
```

### 🛡️ Privacy Guarantee

Photon Gallery is built from the ground up on the principle of **absolute data sovereignty**:
- **Zero Internet Tracking**: Photon Gallery contains no analytics SDKs, crash reporters, or advertising networks.
- **100% On-Device AI**: Semantic search, face clustering, and OCR models execute entirely on your device's neural/CPU hardware. No image or metadata ever leaves your device.
- **Open & Verifiable**: Every line of source code is available in this repository under the GPL-3.0 license for independent inspection.
